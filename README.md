# Discord Rich Presence для Яндекс Музыки (навайбкодил секретным дипсик апи)

Показывает в Discord статус «Слушает …» с названием трека, исполнителем, обложкой альбома и
кнопкой «Открыть в Яндекс Музыке». Работает с приложением Яндекс Музыки для Windows:
читает системную медиа-сессию через Windows SMTC, без сторонних API и логина в аккаунт.

```
Слушает Яндекс Музыку
  Кино — Группа крови
  [обложка]        ⏸ 2:14 / 4:49
  [Открыть в Яндекс Музыке]
```

## Возможности

- Статус «Слушает» с названием, исполнителем и альбомом.
- Обложка альбома, загруженная из медиа-сессии Windows.
- Кнопка-ссылка на поиск трека в Яндекс Музыке.
- Прогресс-бар с оставшимся временем; для радио и рекламы не показывается.
- Иконка в системном трее: пауза, перезапуск, открыть лог, выход.
- Автозапуск с Windows (включается галочкой в меню трея).
- Переживает перезапуск Discord: переподключается с нарастающей паузой.
- Кэш обложек в SQLite — один трек загружается один раз.
- Работа без консольного окна под `pythonw`, логи в `yandex_music_rpc.log`.
- Защита от запуска двух копий одновременно.
- Сборка в standalone `.exe` через PyInstaller.

## Требования

- Windows 10/11
- Python 3.10 или новее
- Запущенные Discord и приложение Яндекс Музыки
- Приложение Discord (Application) — см. настройку ниже

## Настройка

### 1. Создай приложение Discord

1. Открой [Discord Developer Portal](https://discord.com/developers/applications).
2. **New Application** → введи любое название (оно будет видно в статусе).
3. На странице **General Information** скопируй **Application ID** — это твой `client_id`.
4. Название приложения — это то, что Discord напишет мелким шрифтом под статусом,
   например «Yandex Music». Загружать ассеты не нужно: обложка берётся из ссылки.

> Отдельный «Rich Presence» ассет не требуется. Discord принимает внешние URL в
> `large_image`, поэтому используется ссылка на загруженную обложку.

### 2. Получи ключ ImgBB (опционально)

Обложка загружается на хостинг изображений и передаётся Discord ссылкой.

1. Зарегистрируйся на [imgbb.com](https://imgbb.com) и получи API-ключ:
   [api.imgbb.com](https://api.imgbb.com/) → **Get API key**.
2. Вставь ключ в конфиг (шаг 3).

**Ключ не обязателен.** Если его нет или ImgBB недоступен, программа автоматически
переключится на резервный хостинг `uguu.se` (без ключа, файлы живут около 3 часов).
Статус в Discord будет работать в обоих случаях — разница только в сроке жизни ссылки.

### 3. Заполни конфиг

Скопируй `config.example.json` в `config.json` и вставь свои значения:

```json
{
  "client_id": "123456789012345678",
  "imgbb_key": "твой_ключ_imgbb"
}
```

Вместо файла можно использовать переменные окружения — они имеют приоритет:

```powershell
set DISCORD_CLIENT_ID=123456789012345678
set IMGBB_API_KEY=твой_ключ
```

### 4. Включи приложение Яндекса как медиа-источник

Приложение Яндекс Музыки для Windows должно отдавать данные в системный медиа-плеер.
Обычно это работает из коробки. Проверь командой `--check` (см. ниже) — в списке
сессий должна появиться строка с `ru.yandex.desktop.music` и пометкой «будет использоваться».

## Запуск

```bash
pip install -r requirements.txt

python yandex_music_rpc.py            # иконка в трее
python yandex_music_rpc.py --console  # без трея, вывод в консоль
python yandex_music_rpc.py --check    # диагностика: медиа-сессии, Discord, хостинги
python yandex_music_rpc.py --once     # отправить статус один раз и выйти
```

Без окна консоли:

```bash
pythonw yandex_music_rpc.py
```

## Автозапуск

Галочка **«Автозапуск с Windows»** в меню трея. Либо из командной строки:

```bash
python yandex_music_rpc.py --install-autostart
python yandex_music_rpc.py --uninstall-autostart
```

Запись создаётся в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`,
права администратора не нужны.

## Сборка .exe

```bash
python build.py            # dist/YandexMusicRPC/ (папка)
python build.py --onefile  # один файл, стартует медленнее
```

Скрипт сам создаёт иконку, собирает программу и кладёт `config.json` рядом с `.exe`.
Готовую папку можно переносить куда угодно — Python на целевой машине не нужен.
Размер сборки около 120 МБ, потому что внутрь попадают Python и winsdk.

## Меню в трее

| Пункт | Действие |
|---|---|
| Название трека | текущий трек (некликабельно) |
| Пауза / Продолжить | приостановить обновление статуса |
| Перезапустить | пересоздать подключение к Discord |
| Автозапуск с Windows | включить/выключить автозапуск |
| Открыть лог | открыть `yandex_music_rpc.log` |
| Выход | очистить статус и закрыть программу |

## Коды выхода

| Код | Значение |
|---|---|
| 0 | успешное завершение |
| 1 | нет конфига / не запустился / уже запущен |

## Известные особенности

- **Работает только с Яндекс Музыкой.** Поиск сессии идёт по подстроке `yandex` в
  идентификаторе приложения. Для другого плеера измени функцию `is_yandex_session`.
- **Только Windows.** Используются `winsdk` (SMTC) и Win32-трей.
- **ImgBB может быть заблокирован.** В некоторых сетях путь `/1/upload` не отвечает.
  Программа это определяет и переходит на `uguu.se`; ссылки на нём временные,
  поэтому в кэше для них задан срок жизни.
- **Задержка до 1 секунды** на смену статуса — цена опроса медиа-сессии раз в секунду.
- **Не твой Application ID — не твой статус.** Если использовать чужой ID, статус
  будет показан от имени того приложения.

## Приватность

Программа отправляет в Discord название трека, исполнителя, альбом и ссылку на обложку.
Обложка загружается на выбранный хостинг изображений (ImgBB или uguu.se). Ничего
не отправляется куда-либо ещё; переписка и данные аккаунта не затрагиваются.
Ключи хранятся локально в `config.json` или переменных окружения.
